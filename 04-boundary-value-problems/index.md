# Boundary value problems

ODEs with conditions at both ends, solved by relaxation and by shooting.

## Learning goals

- Assemble and solve a linear system for a BVP
- Apply boundary conditions in a derivative matrix
- Use shooting with a secant update for a nonlinear BVP
