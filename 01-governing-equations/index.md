# Governing equations and model resolution

The conservation laws behind every model in the course, and how averaging determines what a model resolves.

## Learning goals

- State the mass and momentum equations at each averaging level
- Distinguish DNS, LES, RANS, shallow-water and 1D models
- Estimate how computational cost scales with Reynolds number
